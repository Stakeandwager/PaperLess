# PaperLess

PaperLess is a lightweight invoicing platform built for small businesses.

## Mission

Help business owners create and send professional invoices and receipts in under 30 seconds.

## MVP Features

- Create invoices
- Auto-calculate totals
- Generate PDF
- Share via WhatsApp
- Generate payment receipts

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- jsPDF

## Future Features

- Customer Management
- Inventory
- Sales Dashboard
- Business Analytics
- Online Payments
